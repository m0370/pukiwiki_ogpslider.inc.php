# PukiWiki OGP Slider

画像とページタイトルを横一列に並べ、横スクロールで読めるブログカードプラグインです。複数のURLを指定する方法と、最近更新したWikiページから自動で選ぶ方法があります。

ファイル名は **`ogpslider.inc.php`**、呼び出しは **`#ogpslider(...)`** です。バージョンは1.1.0。

**[配布ZIPをダウンロード](https://github.com/m0370/pukiwiki_ogpslider.inc.php/releases/download/v1.1.0/pukiwiki-ogpslider-1.1.0.zip)** ／ [リリース一覧](https://github.com/m0370/pukiwiki_ogpslider.inc.php/releases)

## 動作環境

- PukiWiki 1.5.4 UTF-8版
- PHP 8.1以上を推奨（PHP 8.5で検証）
- [ogp.inc.php v3.0以降](https://github.com/m0370/pukiwiki_ogp.inc.php)と、その依存ファイル `opengraph.php`
- CSS Flexbox・scroll-snapに対応したブラウザ

本プラグインはOGPの取得機能を追加せず、既存の `ogp.inc.php` を呼び出します。CSSとJavaScriptは内蔵しており、スキンの編集は不要です。

## 設置

1. 依存する[OGPプラグイン](https://github.com/m0370/pukiwiki_ogp.inc.php)を設置し、通常の `#ogp(URL)` が表示できることを確認します。
2. このリポジトリの **`ogpslider.inc.php`** をダウンロードし、FTPでPukiWikiの **`plugin/`** にアップロードします。
3. Wikiページに、以下の記法を追加して保存します。

PHPから `cache/ogp/` へ書き込める必要があります。未作成なら自動作成を試みます。作成できない場合はFTPで用意し、ホスティングの指定に従って書き込み権限を設定してください。APIキーやアカウント登録は不要です。

## URLを指定する

```text
#ogpslider(max=6,https://example.com/article1,https://example.org/article2,https://example.net/article3)
```

URLの指定順に表示します。同じURLの重複は取り除きます。`max` は**カードの総数**で、画面内に同時表示する枚数ではありません。省略すると6件、指定範囲は1〜20件です。上限を超えた分はOGPも取得しません。

カンマを含むURLはPukiWikiの引数規則に従い、次のように引用符で囲みます。

```text
#ogpslider(max=3,"https://example.com/articles?ids=1,2",https://example.org/news)
```

HTTP/HTTPSのURLだけを受け付けます。URLに埋め込んだユーザー名・パスワード、制御文字などは拒否します。

## 最近更新されたページを表示する

```text
#ogpslider(recent,max=6)
```

特定の階層だけを対象にするには `prefix` を指定します。

```text
#ogpslider(recent,max=6,prefix=日記/)
```

標準の `#recent` と同じ `cache/recent.dat` を読み、更新の新しい順に選びます。`#recent(...)` を引数に埋め込む方式ではありません。古い記事を編集した場合も、その記事が上位に来ます。

`prefix` はページ名の前方一致です。正規表現ではありません。`日記/` と指定するとその階層内が対象になります。`recent` と個別URLの併用、`recent` なしの `prefix` は使えません。

次のページは除外し、その後の対象から最大件数まで選びます。

- 閲覧権限のないページ、一覧除外設定（`$non_list`）に該当するページ
- 削除済みページ、更新履歴ページ自身、カードを設置した現在のページ

探索範囲は `recent.dat` に保存された履歴です。PukiWikiの更新履歴設定によっては、指定した件数より少なくなります。履歴ファイルがなければ本体の再生成処理を呼びます。ページを再表示すると一覧を選び直しますが、開いたまま自動更新する機能はありません。

## 表示と操作

画像は16:9で切り抜き、タイトルをその下に表示します。説明文とURL欄は隠します。OGPや画像を取得できなくても、画像なしのカードとリンクを残します。

スライダー外枠には左右8pxの余白を設けています。`box-sizing: border-box`の内側へ余白を取るため、表示領域から横にはみ出しません。

左右ボタンはカード画像の上に重ねて表示します。マウス操作のPCでは、スライダーへマウスを重ねたとき、またはキーボードフォーカスが入ったときに現れます。タッチ端末ではボタンを常時表示し、指のスワイプと両方を使えます。一覧にフォーカスを合わせると左右キーでも移動できます。スクロール位置に応じて、それ以上進めない側のボタンは隠れます。PCでのマウスドラッグによる移動と自動再生は実装していません。

JavaScriptが無効でも横スクロールとリンクは使えます。同じページへの複数設置や、通常の `#ogp` との併用にも対応します。

### 階層付きタイトルの短縮

同一ホストのカードは、最後の `/` より後ろだけを表示します。

```text
日記/2026年/7月29日/新しい記事 → 新しい記事
```

タイトル末尾の ` - サイト名` がPukiWikiの `$page_title` と一致すれば、その部分も取り除きます。ホスト比較では先頭の `www.` を無視します。外部ホストのタイトル、リンク先、共有キャッシュの内容は変更しません。取得失敗時のURLリンクは短縮対象外です。

## キャッシュ

OGP情報と画像は **既存の `ogp.inc.php` の `cache/ogp/` を共有**します。スライダー独自のキャッシュやAPIキーはありません。

取得・有効期限・失敗時の再試行・キャッシュ修復は、導入したOGPプラグインの仕様に従います。未キャッシュのURLは順番に取得するため、初回は時間がかかることがあります。通常の `#ogp` と同じ方法でキャッシュを管理してください。

## 表示件数の設定

標準値を変える場合は、プラグイン読み込み前の `pukiwiki.ini.php` などで定義します。

```php
define('PLUGIN_OGPSLIDER_DEFAULT_MAX', 6); // max省略時
define('PLUGIN_OGPSLIDER_MAX', 20);        // 指定可能な上限
```

件数を増やすと初回の外部取得が増える点に注意してください。

## 利用上の注意

- UTF-8版を対象とします。EUC-JP版は未検証です。
- 外部URL・OGP・画像の取得は依存プラグインが担当します。本プラグインのURL形式チェックは、内部ネットワークへのアクセス（SSRF）を防ぐ仕組みではありません。信頼できない利用者がURLを登録できる環境では、依存プラグインやサーバー側の通信制限を確認してください。
- 認証トークン・個人情報を含むURLは指定しないでください。URLとOGP情報は依存プラグインのキャッシュに保存されます。認証が必要なページのOGP取得では、閲覧者の認証状態は引き継がれません。
- Markdownプラグインとの連携は同梱しません。HTMLキャッシュを利用する独自プラグインでは、`recent` の再評価と閲覧権限を考慮する必要があります。認証済みユーザー向けのカードHTMLを、他の利用者と共有しないでください。
- インラインCSS/JavaScriptを禁止するCSPでは、表示・操作が制限されます。サイトの方針に合わせた別ファイル化が必要です。

## 開発時の確認

```sh
php -l ogpslider.inc.php
php tests/run.php
```

テストは合成データを使い、一時ディレクトリで動作します。本番のWiki・OGPキャッシュや外部サイトへアクセスしません。OGPプラグインの取得処理自体のテストではありません。

公開時に、合成データによる49項目の検証、PukiWiki 1.5.4と公開版OGPプラグインでのキャッシュ共有・権限制御など7項目の検証を実施しました。Chromiumの自動ブラウザでも左右ボタン・キーボード・複数設置・タッチスワイプ・JavaScript無効時の表示を確認しています。タッチ操作は端末エミュレーションで、スマートフォン実機とEUC-JP版は未検証です。
